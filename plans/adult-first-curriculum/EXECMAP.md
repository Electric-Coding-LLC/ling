# Adult-First Curriculum

## Goal

Make Ling's current seed network explicitly teach Japanese to an adult learner through useful adult situations, direct explanation, and serious practice.

## Guardrails

- Keep the current network topology, station routes, progress boundaries, and review interactions unchanged.
- Preserve existing vocabulary item IDs and stored knowledge; improve framing and examples without invalidating learner state.
- Keep the Japan line's practical travel content and the technical Sound, Kana, and Kanji foundations intact except where orientation copy needs alignment.
- Replace textbook-generic Grammar examples with credible adult identity, work, travel, scheduling, service, and social situations while preserving each station's grammatical scope.
- Define linguistic terminology when it appears; do not hide required knowledge behind unexplained jargon.
- Add no scores, streaks, mascots, childish praise, generic course machinery, or speculative stations.
- Do not commit, push, publish, or deploy without separate authorization.

## Execution Map

- [x] Add adult-first teaching and content-selection rules to the canonical product vision.
- [x] Audit and revise current Foundation and Vocabulary orientation copy so every territory states an adult purpose.
- [x] Replace generic Grammar sentences and explanations with an adult-useful set while preserving station scope and review contracts.
- [x] Generate and verify any changed bundled Grammar audio; update focused curriculum and rendered contracts.
- [x] Run the repository gate, inspect the final diff, and verify representative adult-first routes before closing the plan.

## Done When

- The product vision explicitly names adults as the learner and adult agency as the curriculum-selection rule.
- The existing network remains stable while its category and station copy explains why each territory matters to an adult learner.
- Grammar examples describe credible adult identity, work, travel, scheduling, services, preferences, or relationships rather than generic classroom objects.
- Linguistic terms used in Grammar have concise, accessible definitions.
- Audio, focused curriculum contracts, the full repository gate, and representative route inspection pass.
